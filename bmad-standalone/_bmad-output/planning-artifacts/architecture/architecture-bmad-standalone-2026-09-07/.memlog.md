- (decision) Paradigm: Game Loop + Finite State Machine, plain (no MVC split). FSM states map 1:1 to EXPERIENCE.md (Playing/Paused/GameOver). Binds: all epics. Prevents: divergent control-flow structures across Core Gameplay/Scoring/Session Control epics. Rejected: ECS (no payoff for one active piece + static grid), full MVC (unneeded ceremony at this scope).
- (decision) State ownership: a single update(dt) is the only mutator of the shared state object; scoring/line-clear/level-up happen inline in that same pass, no event bus/pub-sub. Render and input handlers only read state. Binds: all epics. Prevents: hidden/competing mutation paths.
- (decision) Loop timing: requestAnimationFrame with a delta-time accumulator, not setInterval. Binds: Core Gameplay Loop, Session Control (pause must halt the accumulator, not just skip rendering). Prevents: frame-rate-dependent fall speed, inconsistent pause semantics.
- (decision) Script organization: single inline <script>, IIFE-wrapped, sections for state/input/update/render/main. No inline ES modules, no external files (single-HTML-file constraint). Binds: all epics.
- (decision) Board representation: board[row][col], 2D array, 20 rows x 10 cols (row-major), cell = null | pieceColorKey. Binds: Core Gameplay Loop, Session Control (restart resets this shape), rendering. Prevents: divergent grid indexing between spawn/collision/render/reset.
- (decision) Piece shapes: one shared constant lookup table (7 piece types x 4 rotation states x cell offsets), read by spawn, rotation-collision-check, and render. Binds: Core Gameplay Loop. Prevents: visual/collision mismatch from re-derived shape data.
- (decision) Next-piece queue: shared array, length >=1, refilled by spawn logic (write), peeked read-only by preview render. Binds: Core Gameplay Loop (FR-1), Session Control (FR-10 preview). Randomization algorithm (7-bag vs uniform-random) is Deferred — doesn't cross epic boundaries, only spawn logic reads/writes it.
- (decision) Deployment/operational envelope: none by design — static single HTML file opened directly via file://, no server, build, CI/CD, or environments. Explicitly stated rather than left silent, per PRD's zero-dependency/offline constraint.
